# Top 250 Unseen

A small personal cinema utility.

It takes the IMDb Top 250 and removes films the user has already watched according to their Letterboxd data, then exposes the remaining films as a Stremio catalog.

The product should feel:
- premium
- simple
- calm
- cinematic
- trustworthy
- extremely easy to understand

It is not a streaming service, social network, or generic SaaS dashboard.

Core UX:
Import Letterboxd → process → review exceptional matches → generate → install in Stremio.
